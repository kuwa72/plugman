# Plugman - VST Plugin Manager

[日本語版はこちら / Japanese version](README.ja.md)

A desktop application (Electron) that scans large numbers of locally installed VST plugins (VST2, VST3), automatically classifies them and generates descriptions with Gemini AI, and lets you safely move unwanted plugins to the Recycle Bin.

## Features
- **Automatic scanning**: Automatically scans plugins (`.dll`, `.vst3`) from standard VST directories on Windows. Custom directories can also be added.
- **AI classification & descriptions with Gemini**: From each plugin's file name and path, the AI identifies the product name, manufacturer, and category (synth, EQ, compressor, etc.) and generates a concise description. Batch analysis sends multiple plugins per request with deterministic (temperature 0) output for consistent results, and VST3 `moduleinfo.json` metadata is used as ground truth when available.
- **Multi-language UI**: English, Japanese, German, French, Spanish, Chinese, and Korean. The UI language is auto-detected from your OS locale and can be changed in Settings; AI descriptions follow the selected language.
- **Smart cache**: Parsed plugin information is cached locally, so subsequent scans finish instantly.
- **Safe removal**: Unwanted plugins are moved to the Windows Recycle Bin, so you can easily restore them if deleted by mistake.
- **Explorer integration**: Open the folder containing a plugin with a single click.
- **Beautiful dark theme**: A polished Tokyo Night-inspired dark mode UI.

## Setup & Launch

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Launch the application**:
   ```bash
   npm start
   ```

3. **Configure your Gemini API key**:
   - After launching the app, open the **Settings** tab in the sidebar.
   - Enter an API key, which you can obtain for free from [Google AI Studio](https://aistudio.google.com/), and click "Save settings".
   - Note: Without an API key, plugin detection and removal still work, but AI classification and description generation are unavailable.

4. **Build and install the executable**:
   - **Linux / WSL**:
     ```bash
     ./scripts/install.sh
     ```
   - **Windows (PowerShell)**:
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
     ```
   - Install location: `%LOCALAPPDATA%\Programs\Plugman\Plugman.exe` (`C:\Users\<username>\AppData\Local\Programs\Plugman\Plugman.exe`)
   - Shortcuts are automatically created in the Start Menu and on the Desktop.

5. **Launch**:
   - Start from the **Plugman** shortcut in the Start Menu or on the Desktop
   - Or from PowerShell:
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
     ```

## Build & Release
- **Local build (EXE + ZIP)**:
  - Bash: `./scripts/build.sh --zip`
  - PowerShell: `powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Zip`
- **Automated build & release via GitHub Actions**:
  - Pushing a `v*` tag (e.g. `v1.0.1`) triggers GitHub Actions to compile and package the Windows binary, then publish a ZIP and a SHA256 checksum to GitHub Releases.
  - Release scripts:
    - Bash: `./scripts/release.sh [version]`
    - PowerShell: `powershell -ExecutionPolicy Bypass -File .\scripts\release.ps1 [-Version <version>]`

## Directory Structure
- `main.js`: Electron main process (file operations, Gemini API communication, remove/open handling, etc.)
- `preload.js`: Bridge that securely exposes APIs to the renderer process
- `index.html`: UI structure
- `index.css`: Application design (CSS)
- `renderer.js`: Dynamic UI logic, controls for scanning and batch analysis
- `vst_scanner.cpp`: Native C++ scanner for fast VST2/VST3 metadata extraction
- `assets/`: Application icon (`icon.ico`, `icon.png`, generated by `scripts/make_icon.py`)
- `scripts/`: Automation scripts for build, install, launch, and release
- `.github/workflows/release.yml`: GitHub Actions CI/CD build & release workflow
- `package.json`: Dependency and build script definitions
